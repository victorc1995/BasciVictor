# Dashboard Financeiro Autônomo — Victor & Letícia (CBMRS / BMRS)

Aplicação web completa em Next.js + TypeScript + Tailwind CSS, **100% independente de planilhas** (sem necessidade de Google Sheets API).

## Como substituir no seu projeto GitHub / Antigravity

1. Extraia os arquivos deste `.zip` na raiz do seu repositório (substituindo os arquivos antigos).
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Rode localmente para testar:
   ```bash
   npm run dev
   ```
4. Suba para o GitHub (`git add . && git commit -m "Versao autonoma sem planilha" && git push`) — a Vercel fará o deploy automático em segundos!
